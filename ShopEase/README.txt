# ShopEase - Web Technology Lab Mini Project

## Files
- `index.html` - home page
- `products.html` - product list, search, category filters, cart and product details popup
- `about.html` - about, mission and vision
- `contact.html` - contact form with basic validation
- `style.css` - shared responsive styles and dark theme
- `script.js` - basic JavaScript interactions

## How to run
1. Extract the ZIP file.
2. Open the `ShopEase` folder in VS Code.
3. Open `index.html` in a browser. You can also use the Live Server extension.
4. Use the navigation links to visit the other pages.

This is a front-end student demo. Product details and contact information are sample data. No real orders, payments, or messages are sent.
